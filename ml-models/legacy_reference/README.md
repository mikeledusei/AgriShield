# Earlier model scripts

Unchanged reference copies of the training, evaluation and maize-outcome scripts.
They are preserved for comparison and for the results already recorded under
`ml-models/research_runs/`; they are **not** supported workflows.

The supported research workflow is the notebook sequence in `ml-models/notebooks/`,
run in order from `00_data_loading.ipynb` to `05_model_comparison.ipynb`.
`ml-models/scripts/` has been removed.

Note: `maize_outcome_experiment.py.txt` has no notebook equivalent. The notebooks
cover the NDVI drought-risk model only, so the maize yield comparison is reproducible
only from this archived copy.
